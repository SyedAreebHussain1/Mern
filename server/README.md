# Express + TypeScript + Mongoose

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

## Clone the repoitory
git clone https://github.com/SyedAreebHussain1/Mern.git
cd mern
cd server

## Install dependencies:
By typing command "yarn install" or "npm install"

### `starting the app`
Now type "npm run dev"
Runs the app in the development mode.\


### Key Libraries inside server
express.js, bcryptjs, mongoose, express, cors

## Configuration(.env file):
config = {
PORT="your-project-port",
MONGO_URI="your-mongo-url",
JWT_SECRET="your-jwt-secret"
};
